<a name="english"></a>
## 🇺🇸 English

**Phantom Launcher** is a high-fidelity, sci-fi themed game launcher designed to organize your game library with a premium, immersive aesthetic. 

> [!IMPORTANT]
> **Platform Support**: This application is currently **Windows-only**.

### Features
*   **Deep Immersion UI**: Cyberpunk/Sci-fi aesthetic with CRT effects and neon accents.
*   **Universal Library**: Manage games from Steam, Xbox, and manual entries.
*   **Internationalization**: Fully localized in English and Spanish.
*   **Auto-Navigation**: Automatically switches to "RECENT" category upon game launch.

### Requirements
*   **Running (Production)**: 
    *   **OS**: Windows 10/11 (Including LTSC and IoT Enterprise versions).
    *   **Dependencies**: **NONE**. The launcher is a completely standalone monolithic executable. You do not need Node.js or any external runtime installed on the target machine.
    *   **Browser**: Any modern web browser (Edge, Chrome, Opera, etc.) to render the UI.
*   **Building (Development)**: 
    *   **Node.js**: v18 or higher.
    *   **.NET Framework 4.5+**: For compiling the native wrappers.

### Installation & Build
```bash
npm install
npm run build
```
Standalone executable will be generated at `phantom_app/Setup.exe`.

## 🇲🇽 Español

**Phantom Launcher** es un lanzador de juegos con temática de ciencia ficción de alta fidelidad, diseñado para organizar tu biblioteca con una estética premium e inmersiva.

*   **Internacionalización**: Totalmente localizado en inglés y español.
*   **Auto-Navegación**: Cambia automáticamente a la categoría "RECientes" al lanzar un juego.

### Requisitos
*   **Ejecución (Producción)**:

    *   **.NET Framework 4.5+**: Para compilar los wrappers nativos.
